# Sales Performance Dashboard using Power BI

## Project Overview
This project presents an interactive Sales Performance Dashboard developed using Power BI. The dashboard provides insights into sales, profit, orders, quantity sold, and regional performance using the Superstore dataset.

## Objectives
- Monitor overall sales performance
- Analyze profit and revenue trends
- Identify top-performing regions and categories
- Support data-driven decision making

## Tools Used
- Power BI
- DAX
- Microsoft Excel / CSV
- Data Visualization

## Dashboard Features
- Total Sales KPI
- Total Profit KPI
- Total Orders KPI
- Total Quantity KPI
- Sales by Region
- Sales by Category
- Profit by Category
- Interactive Filters

## Dataset
Dataset
The dataset used in this project is sourced from Kaggle.
Dataset link: https://www.kaggle.com/datasets/vivek468/superstore-dataset-final
Source: Kaggle
